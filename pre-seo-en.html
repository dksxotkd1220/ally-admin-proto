FAQ

Questions before you start.

What exactly are SEO, GEO, and AEO?
SEO (Search Engine Optimization) is optimizing for search engines like Google. GEO (Generative Engine Optimization) is optimizing for AI search engines like ChatGPT and Perplexity. AEO (Answer Engine Optimization) is optimizing for voice search and answer engines like Featured Snippets. All three are directly influenced by text content quality on a page, and image alt text is one of the key sources.
Does image alt text actually affect search rankings?
Yes. Google officially uses image alt text as a primary text signal for understanding image content. It directly affects image search result rankings and contributes to the overall SEO context of a page. The more accurate and numerous the keywords in the alt text, the broader the long-tail search exposure.
How do AI search engines (ChatGPT, Perplexity) read images?
AI search engines collect text content from web pages when crawling. They don't analyze image files directly — they recognize the text in the alt attribute as the image's content. So if alt text is empty or overly simple like "image," that image's information never enters the AI search database.
Do I need a developer to get started?
No. Just install the WordPress plugin and enter your API key. No server configuration or source code changes needed. All settings are done from the WordPress admin panel.
Can existing images be retroactively covered?
Yes. The bulk processing feature lets you apply descriptions to all existing images in your media library at once. For sites that have been running without alt text, starting with existing images delivers the fastest SEO improvement.
What languages does A11Y support?
A11Y supports both English and Korean. Descriptions are generated with natural, language-appropriate keywords and phrasing, covering Google Image Search and broader SEO for each language.
