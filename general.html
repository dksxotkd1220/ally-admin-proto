사용 방법

세 단계로 끝납니다.

방식은 달라도 결과는 같습니다. WCAG 2.2 기준의 제대로 된 대체 텍스트.

STEP 01

이미지를 가져오세요

URL 입력, 파일 업로드, 폴더 드래그, 플랫폼 연결 중 하나를 선택합니다. 앨리가 이미지를 자동으로 감지하고 목록을 만듭니다.

URL 파일 폴더 플랫폼
STEP 02

AI가 설명을 생성합니다

WCAG 2.2 기준으로 학습한 AI가 각 이미지를 분석합니다. 표·차트 안의 데이터까지 빠짐없이 텍스트로 변환합니다.

WCAG 2.2 표·차트 지원
STEP 03

검토 후 내보내세요

생성된 설명을 확인하고 직접 수정할 수 있습니다. CSV, JSON 형식으로 내보내거나 연결된 플랫폼에 바로 적용합니다.

접근 방식이 달라도 핵심은 같습니다. 어떤 방식으로 이미지를 가져오든, 앨리의 AI는 동일하게 작동합니다.

WCAG 2.2 기준

국제 웹 접근성 표준으로 학습된 AI가 설명을 생성합니다. 표·차트 같은 복잡한 이미지도 정보 그대로 전달합니다.

스크린리더 검증

생성된 설명은 실제 스크린리더 환경에서 검증됩니다. 화면을 못 보는 사용자에게 정보가 제대로 들리는지 확인합니다.

변경 이력 기록

어떤 이미지에 어떤 설명을 생성했는지 이력으로 남습니다. 접근성 감사나 시정 요구에 대응할 수 있는 증빙 자료가 됩니다.

자주 묻는 질문

출시 전에 궁금한 것들.

워드프레스를 쓰지 않으면 지금 당장 사용할 수 없나요?
현재 앨리는 워드프레스 플러그인만 지원합니다. URL 스캔, 파일 업로드, 플랫폼 연결 기능은 개발 중이에요. 이메일을 남겨두시면 출시될 때 가장 먼저 알려드립니다.
어떤 파일 형식을 지원하나요?
JPG, PNG, SVG, WebP 이미지 파일을 지원할 예정입니다. 복잡한 인포그래픽, 데이터 차트, 텍스트가 포함된 이미지도 처리할 수 있어요.
생성된 대체 텍스트를 어떻게 내보내나요?
CSV, JSON 형식으로 다운로드하거나 연결된 플랫폼에 직접 적용할 수 있습니다. 생성된 설명은 검토 후 직접 수정도 가능합니다.
Shopify, Wix 같은 플랫폼도 지원하나요?
플랫폼 연결 기능은 준비 중입니다. Shopify, Wix, Squarespace 등 주요 CMS와의 연동을 계획하고 있어요. 구체적인 지원 플랫폼 목록은 출시 시 공개됩니다.
워드프레스 버전과 결과물 품질이 같은가요?
네. 동일한 AI 엔진을 사용하며 WCAG 2.2 기준으로 대체 텍스트를 생성합니다. 표·차트 같은 복잡한 이미지도 정보를 빠짐없이 전달하는 것을 목표로 합니다.
