FAQ

Questions before you start.

Where do I get my API key?
Just enter your email on this page and it's issued immediately. No account registration required — your email is your account. One key per email address; if you lose it, you can get a new confirmation link with the same email.
Do I need a developer to get started?
No. Just install the WordPress plugin and enter your API key. No server configuration or source code changes needed. All settings are done from the WordPress admin panel.
How long does it take to get set up?
Installing the plugin and entering your API key takes about 3 minutes. AI can then generate alt text for newly added images or batch-process existing ones.
Does it apply to the whole site, or can I choose specific pages?
Both. You can apply it to everything at once, or select specific pages and images. WordPress settings let you choose your targets and generate alt text for them.
Does it work for new sites too?
Yes. Just install the plugin on a new site and it works right away. Building descriptions during development means you launch with accessibility already in place.
Does it keep managing images after setup?
Yes. There's an option to automatically detect new images and generate alt text as they're uploaded. It's not a one-and-done tool.
Can you handle certification on my behalf?
No. A11Y does not handle certification. Instead, it automates filling in image alt text — the most commonly flagged item in accessibility reviews — to the required standard. (No tool can guarantee 100% protection from lawsuits or certification.)
