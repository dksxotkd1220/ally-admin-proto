사진 파일 안에는 텍스트가 없습니다. 구글, ChatGPT, 음성 검색 모두 이미지를 설명하는 텍스트를 읽습니다. 설명이 없으면 그 이미지는 검색에 존재하지 않는 것과 같습니다.

SEO

Google 이미지 검색

구글은 이미지 자체를 읽지 못하고, 이미지에 붙은 설명 텍스트를 읽습니다. 설명이 상세할수록 이미지 검색 결과 상위에 노출되고, 더 많은 검색어에 걸립니다.

이미지 검색이 전체 웹 검색의 약 22% alt text 없이는 랭킹 신호 자체가 없어 이미지 검색에 아예 노출되지 않습니다.
GEO

AI 검색 (ChatGPT · Perplexity)

ChatGPT, Perplexity, Gemini 같은 AI 검색 엔진은 웹페이지의 텍스트 콘텐츠를 수집해 답변을 만듭니다. 이미지 속 정보는 alt text로 있어야만 AI가 읽고 인용할 수 있습니다.

AI 검색 사용량 전년 대비 3배 이상 증가 GEO(Generative Engine Optimization)는 이미 SEO만큼 중요한 채널입니다.
AEO

음성 · 답변 엔진

구글 Featured Snippet, 음성 검색은 페이지에서 구조화된 텍스트 정보를 추출합니다. 이미지 설명이 정확하고 상세할수록 관련 질문의 답변으로 채택될 가능성이 높아집니다.

음성 검색 결과의 40.7%가 Featured Snippet 출처 구조화된 alt text는 답변 박스 노출의 핵심 소스 중 하나입니다.

도입 전에 궁금한 것들.

SEO · GEO · AEO가 정확히 무엇인가요?
SEO(Search Engine Optimization)는 구글 등 검색 엔진 최적화, GEO(Generative Engine Optimization)는 ChatGPT·Perplexity 같은 AI 검색 엔진 최적화, AEO(Answer Engine Optimization)는 음성 검색과 Featured Snippet 같은 답변 엔진 최적화입니다. 셋 모두 페이지의 텍스트 콘텐츠 품질에 직접적으로 영향받으며, 이미지 alt text는 그 핵심 소스 중 하나입니다.
이미지 alt text가 실제로 검색 순위에 영향을 주나요?
네. 구글은 이미지 alt text를 이미지 콘텐츠를 이해하는 주요 텍스트 신호로 공식적으로 활용합니다. 특히 이미지 검색 결과 순위에 직접 반영되며, 페이지 전체 SEO 맥락에도 기여합니다. alt text에 담긴 키워드가 많고 정확할수록 롱테일 검색에서의 노출 범위도 넓어집니다.
AI 검색(ChatGPT, Perplexity)은 어떻게 이미지를 읽나요?
AI 검색 엔진은 웹 크롤링 시 HTML의 텍스트 콘텐츠를 수집합니다. 이미지 파일 자체는 분석하지 않고, alt 속성에 있는 텍스트를 이미지의 내용으로 인식합니다. 따라서 alt text가 비어 있거나 "이미지"처럼 단순하면 그 이미지의 정보는 AI 검색 데이터베이스에 들어가지 않습니다.
적용하려면 개발이 꼭 필요한가요?
아니요. 워드프레스 플러그인을 설치하고 발급받은 API 키만 입력하면 작동합니다. 서버 설정이나 기존 소스코드 수정이 필요 없어요. 모든 설정은 워드프레스 관리자 화면에서 끝납니다.
기존에 올라가 있는 이미지에도 소급 적용되나요?
네. 일괄 처리 기능을 통해 기존 미디어 라이브러리의 이미지에도 한번에 적용할 수 있습니다. 오랫동안 alt text 없이 운영했던 사이트라면 기존 이미지부터 시작하는 것이 SEO 개선 효과가 빠릅니다.
한국어 키워드도 제대로 최적화되나요?
네. 앨리는 한국어로 학습된 이미지 설명 생성 기능을 제공합니다. 국내 사이트에 맞는 한국어 키워드와 표현으로 alt text를 생성하여 네이버 이미지 검색을 포함한 국내 SEO에도 적용됩니다.
